# Resumen del Proyecto: Calculadora de Terminal



Este proyecto es un programa de terminal desarrollado en C# que permite realizar operaciones aritméticas básicas. Es un experimento que demuestra la capacidad de crear una aplicación interactiva en la consola.

**Características Principales:**

1.  **Interfaz de Usuario:**
    *   **Menú de Operaciones:** Muestra un menú con opciones numeradas para las operaciones disponibles: multiplicación, suma, resta y división.
    *   **Solicitud de Entrada:** Pide al usuario que elija una operación introduciendo el número correspondiente.
    *   **Entrada de Números:** Solicita al usuario que ingrese dos números para realizar la operación elegida.
    *   **Visualización de Resultados:** Muestra el resultado de la operación realizada.
2.  **Operaciones Aritméticas:**
    *   **Multiplicación:** Calcula el producto de dos números.
    *   **Suma:** Calcula la suma de dos números.
    *   **Resta:** Calcula la diferencia entre dos números.
    *   **División:** Calcula el cociente de dos números.
3.  **Lógica del Programa:**
    *   **Elección de Operación:** Utiliza una estructura `if` para ejecutar el bloque de código correspondiente a la operación elegida por el usuario.
    *   **Conversión de Entrada:** Convierte las entradas de texto a números enteros usando `Convert.ToInt32()`.
    *   **Salida de Resultados:** Imprime el resultado de cada operación en la consola utilizando `Console.WriteLine()`.

**Tecnologías Utilizadas:**

*   **C#:** Lenguaje de programación utilizado para desarrollar la aplicación.
*   **.NET Framework:** Entorno de ejecución para el programa.
*   **Console:** Para la interfaz de usuario en la terminal.

**Propósito:**

Este programa es un experimento sencillo diseñado para practicar la interacción del usuario con la terminal, utilizando C# para realizar operaciones aritméticas básicas. Sirve como una demostración inicial de la capacidad de desarrollar aplicaciones interactivas en la consola.

**Para un Trabajo:**

Este proyecto es una implementación básica de una calculadora de terminal. Se enfoca en la lógica de control y la manipulación de datos básicos en C#. Es un buen ejemplo de una aplicación sencilla para empezar a practicar con el lenguaje de programación y puede servir como punto de partida para construir programas más complejos.
